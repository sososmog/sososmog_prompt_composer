# Composer · 模块化提示词构建工具

像搭积木一样组装 AI 提示词的桌面应用。支持 Windows、macOS、Linux。

## 下载安装

前往 [GitHub Releases](https://github.com/sososmog/sososmog_prompt_composer/releases) 下载最新版本：

| 平台 | 安装包 |
| --- | --- |
| Windows | `.exe`（推荐）或 `.msi` |
| macOS | `.dmg` |
| Linux | `.deb` / `.rpm` / `.AppImage` |

> Windows 10 用户若打开后白屏，需安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Windows 11 已内置）。

安装后应用会自动检查更新——发现新版本时只在设置页提示，**不会自动升级**，下载安装完全由你手动触发。也可以在「设置 → 通用」关闭自动检查。

## 功能

### 模块化装配

把提示词拆成独立模块（角色、场景、问题、规则、工作流程、输出格式……），在装配区自由组合。每个模块可改名、编辑、启用/停用、拖动排序。

### 变量系统

在模块内容里写 `{{名称}}` 即可创建变量，右栏统一填写变量值。变量名中英共用，值按语言分别维护。

### 中英双语

界面和内容都支持中英双语。右栏有 Token 估算对比卡，一眼看出两种语言各占多少 token。

### 行内自动补全

打字时编辑区会以灰字预览接续内容，`Tab` / `→` 采纳、`Esc` 取消。候选来源：

- 内置常用句和快速段落
- **本地自学习引擎**——每次复制或导出文本时自动学习其中的子句片段，越用越贴合你的写法

自学习数据只存在本机，可在「设置 → 自学习」查看、删除、导入导出，也可以一键关闭（关闭仅停用，不清除已有数据）。

### 常用句与快速段落

- 每个模块下方有常用句列表，点击即插入光标处，支持自定义增删
- 快速段落是独立功能区，支持分组管理（两级结构：分组 → 段落），点击插入预设文本

### 一键翻译

一键把当前语言的正文翻译到另一种语言。内置 Google Gemini、GLM 智谱、Groq、OpenRouter 以及自定义 OpenAI 兼容端点，在设置面板选择服务商并填写 API Key 即可使用。代码块会被自动跳过不参与翻译，翻译失败不会改动已有内容。

### 配置导入导出

把素材库、变量、设置等打包为 `.json` 备份文件。导入时可预览摘要，按名称智能判重合并。**API Key 从不导出，导入也不会清空本机已有的 Key。**

### 浮窗模式

按全局快捷键（默认 `Ctrl+Alt+C`，可自定义）随时呼出一个置顶小窗，无需切回主窗口即可快速复制内容。

- 浮窗内同样支持行内自动补全，与主窗口共享候选池
- 可缩小为悬浮小球，不占屏幕；单击恢复，按住拖动
- 窗口位置和尺寸会被记住
- **自动粘贴**：开启后点击浮窗内容会自动切回你之前的窗口并粘贴（Windows 已验证，macOS 实验性支持）

### Agent 监控面板

浮窗的第二个 tab——实时查看本机正在运行的 AI coding agent 会话，目前支持 **Claude Code、Codex、Antigravity** 三家。可在设置面板开关。

- 每个会话一张卡片：运行状态、会话标题、git 分支、模型、运行时长、上下文 token 用量
- 按状态分组，「等你回话」的会话排在最前，tab 上有角标计数
- Claude Code 的会话可展开查看 subagent 树——每个子 agent 在做什么、各自的 token 和活跃时间
- 后台 subagent 还在跑时，卡片上会单独标出，不跟主会话状态混淆

这个面板**只看不控**——不会启动、终止任何会话，也不会往 agent 的配置目录写入任何文件。读不出数据时显示「状态未知」而不是猜。

### 其他

- **新手引导**：首次启动有高亮遮罩引导，功能附近有锚定轻提示
- **复制/导出**：一键复制到剪贴板，或导出为 `.md` 文件
- **本地持久化**：所有内容自动保存到本机，重开应用恢复原样
- **深色/浅色主题**：支持手动切换，浮窗自动跟随主窗口

## 数据存储位置

所有数据存在本机应用数据目录，不联网上传：

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\com.composer.app\` |
| macOS | `~/Library/Application Support/com.composer.app/` |
| Linux | `~/.config/com.composer.app/` |

## 常见问题

**快捷键 `Ctrl+Alt+C` 呼不出浮窗**
该快捷键可能已被其他程序占用。在设置面板改绑其他组合即可，注册失败会自动回滚并提示原因。

**浮窗自动粘贴不生效 / 报「没有可粘贴的目标窗口」**
需要先切到目标软件再呼出浮窗，让应用记住你之前的窗口。macOS 还需在「系统设置 → 隐私与安全性 → 辅助功能」中授权。

**一键翻译报错**
先在设置面板确认已选择服务商并填写了有效的 API Key 和模型名。需要能访问对应服务的网络。翻译失败不会改动已有内容。

**导入配置后 API Key 不见了**
这是预期行为——导出永不包含 API Key，导入也不会清空本机 Key。换机器后需要手动重填。

**检测不到新版本**
确认本地网络能访问 GitHub。如果刚发布，等 CI 构建完成（通常几分钟）后再试。

**Agent 面板显示「状态未知」**
面板读取的是各家 agent 写在本地的会话文件，这些属于未公开格式，上游更新后可能暂时读不出来。不影响其他功能。
